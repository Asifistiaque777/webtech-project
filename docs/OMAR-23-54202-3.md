The team project already contained food/parcel cards, add-to-cart, quantity controls, totals, checkout, admin stock management and a rider portal. Those existing features are not claimed as new work in this change.

1. Live item-name search, ignoring letter case and surrounding spaces.
2. All / Food / Parcel category selection, combined with the search.
3. A results count, an empty-results message and a reset button.

## Code explanation

- `showItems()` reads the search and selected category. `trim()` removes surrounding spaces; `toLowerCase()` makes matching case-insensitive. A loop renders an item only when both conditions match. It then updates the result count and hides empty sections.
- `resetFilters()` clears the search, selects All, redraws the list and returns keyboard focus to the search box.
- `removeFromCart(id)` uses `filter()` to keep entries whose IDs differ from the removed item. It saves the new cart, then calls the existing `showCart()` to recalculate the display.
- `addToCart()` and `changeQty()` recheck current availability before increasing the cart. A customer can still reduce or remove an unavailable item.
- `input` and `change` listeners update results immediately. The browser's `storage` event updates the customer view after changes in another tab on the same origin.
- Search and category filtering only change what is displayed; they do not remove items from storage or from the cart.

## Demonstration checklist

Use Live Server and a fresh browser profile if you want the default demo data without affecting an existing cart.

1. Open the customer page: 12 items appear (8 food, 4 parcel).
2. Search `  BURGER  `: only Beef Burger appears.
3. Select Parcel while that search is active: the no-results message appears.
4. Reset filters: all 12 items return.
5. Select Food, then Parcel: 8 and 4 items appear respectively.
6. Add two Beef Burgers and one Cold Drink: subtotal is ৳550, delivery ৳50, total ৳600.
7. Search for another item and reload: the cart remains saved.
8. Remove Beef Burger: Cold Drink remains and the total becomes ৳100.
9. Reduce Cold Drink to zero: the empty-cart message appears and totals disappear. Checkout is blocked.
10. Add Beef Burger. In another tab, sign into admin and mark it out of stock. The customer page updates; increasing its quantity or checking out is blocked. Remove still works. Restore stock after the demonstration.

12. Check the customer page on desktop and mobile widths.
