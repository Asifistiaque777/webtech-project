## Scope of this change

The team project already contained food/parcel cards, add-to-cart, quantity controls, totals, checkout, admin stock management and a rider portal. Those existing features are not claimed as new work in this change.

This branch adds:

1. Live item-name search, ignoring letter case and surrounding spaces.
2. All / Food / Parcel category selection, combined with the search.
3. A results count, an empty-results message and a reset button.
4. A Remove button that deletes the whole cart entry and recalculates totals.
5. Stock checks before adding an item or increasing its quantity.
6. Customer-page refresh when another tab changes stock or the shared cart.
7. Labels, keyboard focus styling and responsive controls for the customer page.
8. Low-to-high and high-to-low price sorting within each category, combined with search and category filtering.
9. A header cart badge showing the sum of quantities, including updates after reload, removal and changes in another tab.
10. A short confirmation naming the item added to the cart; it disappears after 2.5 seconds.

## Code explanation

- `showItems()` reads the search and selected category. `trim()` removes surrounding spaces; `toLowerCase()` makes matching case-insensitive. A loop renders an item only when both conditions match. It then updates the result count and hides empty sections.
- `showItems()` also uses `sort()` with numeric comparison (`a.price - b.price` or the reverse) to sort the fresh array returned by `getItems()`. Food and Parcel keep separate sections. It never saves the sorted array, so the original order in storage stays intact.
- `resetFilters()` clears the search, selects All and Default order, redraws the list and returns keyboard focus to the search box.
- `removeFromCart(id)` uses `filter()` to keep entries whose IDs differ from the removed item. It saves the new cart, then calls the existing `showCart()` to recalculate the display.
- `addToCart()` and `changeQty()` recheck current availability before increasing the cart. A customer can still reduce or remove an unavailable item.
- `input` and `change` listeners update results immediately. The browser's `storage` event updates the customer view after changes in another tab on the same origin.
- Search and category filtering only change what is displayed; they do not remove items from storage or from the cart.
- `showCart()` sums each cart entry's `qty` before checking for an empty cart. Two burgers and one drink show a badge of 3; an empty cart shows 0.
- `showCartMessage()` writes the added item's name with `textContent` and shows a status message. `setTimeout()` hides it after 2500 milliseconds. `clearTimeout()` cancels an earlier timer so a new message is not hidden too soon.

সার্চ বক্সে লেখা এবং ক্যাটাগরি—দুটো শর্ত মিললে আইটেম দেখানো হয়। `includes()` দিয়ে নামের মধ্যে সার্চের শব্দ আছে কি না দেখা হয়। `filter()` দিয়ে নির্দিষ্ট আইটেম বাদ দিয়ে নতুন কার্ট তৈরি করা হয়। কার্ট সেভ হওয়ার পরে আবার দাম হিসাব করে পেজে দেখানো হয়। অ্যাডমিন অন্য ট্যাবে স্টক বদলালে `storage` ইভেন্ট কাস্টমারের পেজ আপডেট করে।

## Demonstration checklist

Use Live Server and a fresh browser profile if you want the default demo data without affecting an existing cart.

1. Open the customer page: 12 items appear (8 food, 4 parcel).
2. Search `  BURGER  `: only Beef Burger appears.
3. Select Parcel while that search is active: the no-results message appears.
4. Reset filters: all 12 items return.
5. Select Food, then Parcel: 8 and 4 items appear respectively.
6. Add two Beef Burgers and one Cold Drink: subtotal is ৳550, delivery ৳50, total ৳600.
7. Search for another item and reload: the cart remains saved.
8. Remove Beef Burger: Cold Drink remains and the total becomes ৳100.
9. Reduce Cold Drink to zero: the empty-cart message appears and totals disappear. Checkout is blocked.
10. Add Beef Burger. In another tab, sign into admin and mark it out of stock. The customer page updates; increasing its quantity or checking out is blocked. Remove still works. Restore stock after the demonstration.
11. Add one Chicken Pizza and proceed to checkout: the summary shows one pizza and a ৳500 total.
12. Check the customer page on desktop and mobile widths.
13. Select Price: Low to high, then High to low. Prices should be sorted inside each section. Search `chicken` and select Food: low-to-high prices are 180, 220, 320 and 450.
14. Reset filters: the search, category and sort order all return to their defaults.
15. Add two burgers and one drink: the header badge shows 3. Increase, decrease and remove entries, then reload: the badge follows the saved quantities.
16. Add one item, then another before the message disappears. The latest item name appears for its own 2.5-second interval. Completing checkout and returning to the customer page resets the badge to 0.
